Accuracy rules

  • EQ: enter the Earthquake count separately for each defense. A defense with 0 EQ receives no EQ damage.

  • Rocket Backpack: check only buildings actually crossed by its line.
  • Fireball: check the target and any buildings actually inside the splash radius.
  • Lightning: use the number of Lv.10 spells allocated to each defense.
  • Clan Castle: Lightning is disabled because Lightning does not damage Clan Castles.
